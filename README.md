# Scientific-Calculator
A modern Scientific Calculator mobile application built with Android Studio and Kotlin. It provides basic and advanced mathematical operations, trigonometric functions, logarithms, powers, roots, constants, calculation history, responsive buttons, and a clean, user-friendly interface designed for students and everyday mathematical problem-solving.

## Scientific Calculator – Android Mobile Application

A fully functional **Scientific Calculator mobile application** developed using **Android Studio**, with **Kotlin and Java**, designed to provide a fast, accurate, and user-friendly solution for both basic and advanced mathematical calculations. The application combines a clean modern interface with powerful scientific operations, making it suitable for students, developers, engineers, and everyday users.

The project follows a structured **Android application architecture**, with the `app` module containing the application's core implementation, resources, manifest configuration, and Kotlin/Java source code. The project also includes **Gradle Kotlin DSL (`.gradle.kts`)** configuration and a centralized `libs.versions.toml` version catalog for organized dependency and build management.

### ✨ Key Features

* ➕ **Basic arithmetic operations** – Addition, subtraction, multiplication, and division.
* 🔢 **Scientific calculations** – Powers, roots, percentages, logarithms, and exponential operations.
* 📐 **Trigonometric functions** – Sin, Cos, Tan and related mathematical operations.
* 🧮 **Advanced mathematical expressions** with support for complex calculations.
* 📜 **Calculation history** for reviewing previous calculations.
* 🔄 **Responsive buttons and interactive UI** for a smooth calculation experience.
* 🌓 **Modern Android interface** designed for readability and usability.
* ⚡ **Fast and accurate calculations** with appropriate mathematical handling.
* 📱 **Mobile-optimized design** suitable for different Android screen sizes.
* 🧹 **Clear/reset functionality** for quickly starting new calculations.
* 🛠️ **Organized project structure** separating application logic, resources, and configuration.

### 🏗️ Project Structure

The project is organized into several important components:

* **`app/`** – Main Android application module.
* **`manifests/`** – Contains `AndroidManifest.xml`, which defines application configuration, activities, permissions, and other Android components.
* **`kotlin+java/`** – Contains the application's Kotlin and Java source code, including the calculator's logic and Android components.
* **`res/`** – Contains application resources such as layouts, drawables, strings, colors, themes, and other UI resources.
* **`keepRules/`** – Contains configuration related to code shrinking/optimization and rules for preserving required classes or members.
* **`build.gradle.kts (Project)`** – Defines project-level Gradle configuration.
* **`build.gradle.kts (Module: app)`** – Controls application-module dependencies, Android configuration, build types, SDK settings, and plugins.
* **`gradle.properties`** – Contains Gradle project properties.
* **`gradle-wrapper.properties`** – Defines the Gradle wrapper configuration used to build the project.
* **`libs.versions.toml`** – Centralizes dependency and plugin versions for easier project maintenance.
* **`local.properties`** – Stores local Android SDK configuration.
* **`settings.gradle.kts`** – Defines project modules and Gradle settings.

### 🎯 Objective

The main objective of this project is to create a **reliable, modern, and beginner-friendly scientific calculator for Android** while demonstrating practical Android development using **Kotlin, Java, Gradle, and Android Studio**. The application provides essential mathematical functionality in a compact mobile interface and can serve as both a useful everyday tool and an educational Android development project.

### 🚀 Future Enhancements

The application can be further expanded with features such as **unit conversion, constants, equation solving, graph plotting, matrix calculations, customizable themes, memory functions, advanced expression parsing, and improved calculation history management**.

Overall, this project demonstrates the development of a complete Android utility application with a structured codebase, modern build configuration, reusable resources, and an intuitive scientific-calculation experience.
